# MAMUT-routing-TDVRPTW-Mamut2026 (retired)

This repository held the first version of the Mamut2026 TDVRPTW instances. That family is retired. It was superseded by a collection regenerated from scratch on a 5-city grid, with shared sidecars and harmonized naming. This collection was renamed Poryos2026 on 2026-07-22 and lives at:

**https://github.com/ANR-MAMUT/MAMUT-routing-Poryos2026**

The name Mamut2026 has been reused since September 2026 for a different collection, [MAMUT-routing-Mamut2026](https://github.com/ANR-MAMUT/MAMUT-routing-Mamut2026). That collection is not the successor of this repository.

The first-version instances remain available in the history of this repository for the record. They are no longer mounted in [MAMUT-routing](https://github.com/ANR-MAMUT/MAMUT-routing), carry no BKS maintenance, and should not be used in new experiments. No name or content overlaps with Poryos2026. The first-version names carry hash suffixes, and the Poryos2026 names follow the pattern `poryos-<city>-n<N>-<method>`.
